# Evidence Review

Local evidence-linked human review for reports, claims and calculations.

## What it does
A reusable Python package and local browser app for inspecting documents against sources and recording human judgments. The tool will automate navigation, metadata, autosave and structured exports.

## Current status and running it
Design/bootstrap only: no runnable application or release yet. See [SPEC.md](SPEC.md) and [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md). Future demo uses artificial data and requires no account or network.

## Verification
No product tests or coverage claims yet. Implementation acceptance includes contract, crash recovery, privacy and actual-browser tests.
